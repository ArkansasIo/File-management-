# Feature status

Included in the initial source push: .NET solution and project skeleton, patient and chart models, specialty chart template registry, required-field validation, EF Core/MySQL context, API health/chart/algorithm endpoints, patient CRUD starter, print text rendering, and MySQL patient/chart schemas.

Incomplete: chart persistence and retrieval, complete CRUD for all clinical modules, authentication, authorization, tenant isolation, audit enforcement, secure document storage, PDF generation, Excel import/export service, and full algorithm implementations. The project has not been compiled or tested in this environment. Do not use real patient data until security and privacy controls are implemented and verified.
